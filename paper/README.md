# Paper — JISA submission package

**Direction Is Not Enough: Trigger Salience and Adaptive Collusion against
Byzantine-Robust Federated Intrusion Detection**
U. Mustafa, I. Rashid.

Targeted at the **Journal of Information Security and Applications** (Elsevier,
ISSN 2214-2126 / 2214-2134), subscription track, via Editorial Manager.
Elsevier `elsarticle` class, `[3p]` single column.

`README.txt` is the submission-facing document — what is in the package, how to
rebuild it, and the five things that still need a human decision. This file is the
developer-facing quick reference.

## Build

```bash
make              # main.pdf
make highlights   # highlights.pdf (5 bullets, each under 85 chars)
make numbers      # regenerate numbers.tex + figs from ../results/, then rebuild
make gate         # submission gate: fails while any \PENDING remains
make check        # gate + abstract length, highlight lengths, build hygiene
make package      # flat submission/ folder for Editorial Manager, then rebuilds it
```

Elsevier forbids subfolders in a submission, so `make package` flattens `figs/` into a
single directory and verifies the flattened copy still compiles.

## The one rule

**No number is typed by hand.** Every number in the prose and in every table is a
macro in `numbers.tex`, generated by `make_numbers.py` from the committed result
JSONs in `../results/`. To change a reported number you change the generator or
the experiment, never the `.tex`.

A configuration that has not been run expands to `\PENDING`, which renders as a red
`[PENDING RUN]` marker. Nothing carrying one may go to a venue.

`make gate` exits non-zero while any number **the manuscript quotes** is unresolved,
and names each one. The generator emits a full grid per family (683 macros) but
`main.tex` quotes 151 of them, so gating on all 683 would demand experiments whose
numbers appear nowhere in the paper. Both counts are printed. `make check` reports the
same total grouped by the lane of `run_remediation.sh` that resolves it, and each
literal `\PENDING` hedge in the prose carries a `% RETIRES WITH:` comment naming its
lane.

Two figures (`fig_dose`, `fig_evasion`) are wrapped in `\IfFileExists`: the moment
`make_figs.py` can draw them from real data, the figure *and its caption* switch
from placeholder to final. There is no manual swap to forget.

## Regenerating from results

`make numbers` runs, in order:

```bash
python3 paper/aggregate_multiseed.py     # collapse ms_*_s{seed}.json to mean/sd
python3 -m experiments.make_tables       # summary.csv, comparison.md
python3 paper/make_numbers.py            # -> paper/numbers.tex
python3 paper/make_figs.py               # -> paper/figs/*.pdf
```

Run it after each lane of `../run_remediation.sh` completes.

## Layout

`[3p]` (single column) is the default: the nine-column headline table fits it
comfortably and it matches the companion Computers & Security submission. JISA
typesets in two columns in print; `README.txt` records the three changes needed to
switch.
